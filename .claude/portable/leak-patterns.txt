# 洩漏偵測 pattern(通用)—— pre-commit 用。每行一條 regex(# 起首為註解)。
#
# **這份只放通用的機密形狀,可以公開。**
# 「揭露我是誰」的具體 token(使用者名稱、實際資料夾名、券商名)不在這裡 ——
# 那些本身就是敏感資料,寫進公開 repo 的 pattern 檔等於公開它們。
# 它們住在 ~/.claude/leak-patterns.local.txt(不進版控,與 g1-protected.txt 同層),
# leak_scan.py 會把兩份聯集起來掃。這是機制/個人資料分離,與 G1 同構。
#
# 方向與其他清單不同:列的是**該擋的東西**,新機密形狀預設漏 ——
# 因為「什麼算機密」是開放集合。誤擋成本(改 pattern)遠低於漏放
# (推上 GitHub 之後只能改寫歷史),所以寧可寬,配人工覆核與本機個人清單。
#
# ── 加一條規則要配什麼(票 108,F-161)────────────────────────
#
# 1. **配一個組裝正樣本**,加進 tests/test_leak_scan.py 的 SAMPLES 表。
#    那張表遍歷本檔的每一條,缺樣本即紅 —— 少了它,新規則加進來會**全綠**,
#    而它從沒被驗證過會命中。
#
# 2. **pattern 字面不得出現在任何進版控的檔案裡** —— 含票面、註解、
#    friction log、README,不只測試檔。本檔自己是唯一的例外(掃描器跳過它)。
#    有些 pattern **自己就打得到自己**(憑證副檔名那三條即是),
#    寫成字面會在 commit 當場被權威層擋下。要提到它們就用敘述,不要貼字面。
#    寫這一句的理由:這條規矩原本只住在 tests/test_leak_scan.py 的檔頭,
#    於是它只對改那個檔的人生效 —— 票 108 在註解與票面連中三次(F-161)。
