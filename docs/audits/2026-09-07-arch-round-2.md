## A 桶 —— 疑似 fail-open(4 條)

### A-1 `_target_allowed` 把相對路徑當成絕對路徑

**出處**

```
.claude/hooks/gate.py:399    "/tmp/": "系統暫存,在 repo 之外",
.claude/hooks/gate.py:400    "scratchpad": "工作階段暫存目錄,在 repo 之外",
.claude/hooks/gate.py:549    haystack = "/" + tok.lstrip("/")
.claude/hooks/gate.py:551        needle = "/" + t.strip("/") + "/"
```

`tok = "tmp/evil.py"` → `haystack = "/tmp/evil.py"` → `needle = "/tmp/"` 命中 → 放行。
`scratchpad` 同理,且是**任意深度**:`a/b/scratchpad/x.py` 也命中。

那兩行註解逐字寫著「**在 repo 之外**」,而比對完全不驗這件事。
票 76 A3 補的是**成分邊界**,沒有補**根錨定**;而 `scanner.py:455-458` 的正典明寫
「**兩種錨定,不要合成一種**」—— `_target_allowed` 的 docstring **引用了那一段**,
只實作了其中一種。**引用一份正典不會讓你實作它。**

`tmp/` 與 `scratchpad/` 都不在 `NON_SOURCE_DIRS`(`gate.py:124-139`),
所以那裡寫進去的是原始碼。提交時 R2/R3 仍看得到 staged 檔案,
所以不是整條穿透 —— 但那正是 ADR 0008 說的「只剩一道」。

**探針(零寫入,純函式,未跑)**

```
gate.bash_write_violation("tee tmp/evil.py")           期望 None
gate.bash_write_violation("tee a/b/scratchpad/x.py")   期望 None
gate.bash_write_violation("rm -rf tmp/")               期望 None   ← 最貴的一格
對照 gate.bash_write_violation("tee pkg/evil.py")      期望擋下(不得變)
對照 gate.bash_write_violation("tee /tmp/x.py")        期望 None(設計許可,不得變)
```

**估工** 小 · **裝新下游前** 要(下游 repo 內很可能真的有 `tmp/`)
**已立案** 票 **111** 第一節
