## 二、⚠ 本表的長度,以及本表自己

**F-137 逐字:一份清單不會帶著它自己的長度。** 所以每一列都標「第 n / 共 34」。

**而票 88 §八之三(五)寫下了更進一步的一句(裁決者原文):**

> ### **一張記錄「規矩只活在散文裡」的表,自己只活在散文裡。**
>
> `F-137` 逐字:一份清單不會帶著它自己的長度 ——
> 本則更進一步:**一份清單也不會把自己算進它盤點的對象裡。**

**所以本表加了第 34 條:本表自己。** 兩邊互指:
本檔 ←→ `docs/tickets/framework-updates/88-g1-level1-does-not-expand-tilde.md` §八之三(五)。

## 四、⚠ 對照組(**不計入 34 條**)—— 「有測試」≠「違反當下會叫」

`CLAUDE.md` 正典段的六條漂移偵測(I1a / I1b / I2 / I3 / I4 / I5)是**有機器**的:
`tests/test_claude_md.py` 與 `tests/test_canon_section.py` 共 **21 條測試**,守著
「正典段提到的規則必須存在」「反向:存在的規則必須被提到」「friction / ADR 引用必須解析得出來」
「正典段不得出現行號引用」「路徑 token 必須分類」。

**放在這裡是因為它證明「有測試」與「違反當下會叫」不是同一件事:**

- `.githooks/pre-commit` 只跑 `leak_scan.py --staged` 與 `gate.py --pre-commit`,**不跑 pytest**
- `.github/workflows/tests.yml` 只在 push / PR to master 觸發

**⇒ 這六條的實際狀態是「叫的時機太晚」。**
而**這是在本庫量到的,不是對測試的一般性懷疑** —— 那正是本表**第 11 條**(元缺口)。
