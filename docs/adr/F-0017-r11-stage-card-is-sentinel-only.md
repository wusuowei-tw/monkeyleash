# ADR F-0017 — R11 只活在前哨（比照 0008）

日期:2026-10-21
狀態:已採納
票:158(`docs/tickets/framework-updates/158-ai-execution-pipeline.md`)

## 決策

R11(AI 用檔案工具寫站牌 `.dev/pipeline.json` → 擋)由前哨述詞 `stage_card_violation(path)` 判定。
`mode_hook` 對 Write / Edit / MultiEdit / NotebookEdit 四種檔案工具,在呼叫 `check()` 與影子分支**之前**
問它;有訊息就硬擋,**不受影子豁免**。

`check()` 與 pre-commit **不判 R11**。`RULE_DIVERGENCE` 登記 R11,目的只是讓這個分歧**看得見**。

## 為什麼不在提交時擋

站牌的合法修改者是**使用者本人**(換站由人改 `current_stage`)。

在下游 repo,站牌是受 git 追蹤的 —— 安裝器不忽略 `.dev/`。使用者手動換站之後,
會把站牌連同其他改動一起 commit。提交時只看得到 staged 內容,**分不出是誰改的**;
在那裡擋 R11,擋到的正是本人。

這與 0008 是同一類:R7 管工具呼叫,R11 管「AI 的檔案工具寫入」——
**規則的對象在提交時已經不存在了**。不是權威層放水,是那個事實在那個時點不存在。

(本 repo 的 `.gitignore` 忽略整個 `.dev/`,站牌本來就不會進 commit;
但這個理由只在本 repo 成立,不能拿來當 R11 的設計依據。)

## 為什麼不留在 `check()` 再加宣告

一個替代做法是把 R11 留在 `check()`、只在寫入時點回報,再在 `RULE_DIVERGENCE` 宣告分歧。
它在本 repo 會綠,在下游會紅:

- 分歧不變式(權威比前哨鬆的案例必須有宣告)會要求宣告指向的 ADR 檔**存在**;
- 而 `docs/adr/` 在 portable-manifest 標 `ask`,**全新安裝不會帶過去**;
- 跑那條不變式的測試檔會跟著安裝出貨,所以下游的測試會因為找不到 ADR 檔而紅。

比照 R7 把 R11 移出 `check()`,不變式就不會判到它(見下一節),下游不受影響。

## 因此:繞過前哨就沒有第二道

R11 的擋下訊息**不套** `sentinel_footer()`。那句話寫「繞過前哨仍會在 commit 被擋」,
對 R11 是假的。宣稱有第二道而實際沒有,比沒有第二道更危險(同 0008)。

R11 目前只涵蓋檔案工具(W1)。其他能改站牌的路徑:

- Shell 類寫入(W2–W4):待票 158 的 C0-3;
- Python 腳本內寫入(W5)、`git stash -a` / `git clean -x`(W6):留待 C2 設計,**不保證能擋**。

## 涵蓋性不變式看不到 R11,這件事也要明寫

不變式的實作是比較 `check()` 兩次呼叫的 trace,而 R11 不住在 `check()` 裡。
所以**那條不變式對 R11 是盲的**,理由與 0008 對 R7 的說明相同。
宣告寫進 `RULE_DIVERGENCE` 讓它至少是**看得見的**,但這裡靠的是宣告,不是機器判定。

## 裁定來源

票 158〈二〉「C0-2 修正」(Jeff 2026-10-21):R11 只在前哨擋,完全比照 R7;
推翻 C0-R0 讀碼時提出的「寫入與提交時都擋」。

## 補充：C0-3 Shell 類（2026-10-21）

`shell_stage_card_violation(command)` 由 `mode_hook` 對 Bash／PowerShell 指令判定,
位置在 R7 與影子分支**之前**,命中就硬擋,不受影子豁免。
它取用的寫入目標**不經過** R7 的許可前綴與 `.dev/` 許可目標,
所以涵蓋 W2–W4 的已列舉寫法(包括 `git …`、`python -m pytest …` 這類許可前綴後面接的重導向)。

目標看不出來時的規則 (c),原文照票 158〈二〉C0-3 裁定:

> 目標看不出來時採「指令字面含 pipeline.json，且 R7 會擋、或內嵌直譯器命中、或任一抽出目標的檔名是 pipeline.json」⇒ 擋；讀取不擋。

從站牌複製**出去**也會被誤擋 —— 抽取器分不出讀寫方向,這是裁定接受的代價。

已知殘留,**不保證能擋**:

- W5:腳本內寫入,含 `python -m json.tool A 站牌`;
- W6;
- PowerShell 短別名與 `.NET` 直接呼叫;
- 以字面拼接繞過 (c)(指令字面不出現 `pipeline.json`)。

前面「因此:繞過前哨就沒有第二道」一節,同樣適用於這一節:Shell 類 R11 的擋下訊息
也不套 `sentinel_footer()`,pre-commit 不判它。

裁定來源:票 158〈二〉「C0-3 裁定」(Jeff 2026-10-21)。
