# ADR 0007 — 本框架在未安裝的副本上只剩前哨

日期:2026-08-09
狀態:已採納(記錄一個**關不掉**的缺陷,不是留白)

## 事實

`.git/hooks/` 依 git 設計不進版控。clone 出來的副本上:

- **前哨在**(`.claude/settings.json` 隨 repo 走)
- **權威層不在**(`.git/hooks/pre-commit` 沒被 clone 帶走)

而且原本**完全靜默**:前哨照跑、測試照綠,`gate.py` 甚至還在擋下訊息裡宣稱
「繞過前哨仍會在 commit 被擋」—— 那句話在未安裝的副本上是假的。
這是 F-009 的最終形式:**規則存在,但整層沒被部署。**

## 為什麼不能自動化掉

`core.hooksPath` 是 **local config,不隨 clone 走**。它把「複製一個檔案」
換成「跑一行 config」,**沒有消除那一步**,只是縮短。

零接觸不可能:**git 刻意不讓 clone 自動執行任何東西。** 那是安全設計,不是缺陷。
所以問題不是「怎麼自動裝」,是「**沒裝的時候誰會叫**」。

## 誰會叫,以及誰不會

| 偵測位置 | 隨 repo 走 | 涵蓋 |
|---|---|---|
| 前哨(`gate.py` 每次判定) | ✅ | 只有 **AI 路徑** |
| 測試(`tests/test_gate.py`) | ✅ | 所有人,但**沒有機制強制它被跑**(F-025) |
| 安裝時強制驗證 | — | 只有**跑過安裝的人** |

**三者都碰不到:clone 下來直接手動 `git commit` 的人。**

## 決策

**承認關不掉,並明寫。** 三個處置:

1. `authoritative_layer()` 判定看**內容**不看檔案存不存在 —— 專案本來就可能有
   自己的 `pre-commit`,只驗檔案在不在的話,別人的 hook 佔著位子會被判成已安裝。
2. `not_installed_notice()` 的訊息裡**直接寫出它涵蓋不到誰**。
   只說「沒裝,請裝」讀起來像裝好就全部關上了,而那是假的。
   有一條測試釘住這句必須在。
3. `CLAUDE.md` 那句「pre-commit 綁得住所有人」已改成
   「**在已安裝的副本上**綁得住所有人」+ 明寫未安裝時不成立。
   (同一句話原本寫在兩個地方,第一次只改了一處 —— F-001 的形狀。)

## 為什麼「明寫」是完整的處置,不是敷衍

同 ADR 0004(閘門自身免 R2)、同 ADR 0006(擋不住刻意偽造證據):
**擋不住就明說擋不住。**

假裝擋得住比擋不住危險 —— 你會停止注意它。
一份宣稱「綁得住所有人」而實際只綁得住一半的文件,讀起來像權威,
於是沒有人再去檢查那一半。這條遞迴有底,**終點是人的審查**(F-034)。
