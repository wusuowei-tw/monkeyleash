# 32 — 多條 pattern 命中同一行時,分段遮罩可以拼回完整祕密

**排程**:執行順序第 3。守衛設計變更,完整流程,紅燈先行。

**來源**:換機器演練卡點 #15。**F-067 家族。**

## 現象

一行文字同時命中兩條(或更多)pattern 時,掃描器**各自遮各自那一段**,
於是輸出兩行報告,而**把兩行併起來讀就還原得出完整的原始行**:

```
行 N  命中 pattern A   內容:<遮罩>xxxx yyyy
行 N  命中 pattern B   內容:aaaa bbbb<遮罩>
```

第一行洩漏了後半,第二行洩漏了前半。**每一行單獨看都合格。**

## 為什麼這是 F-067 家族而不是新東西

F-067 立的規矩是:**掃描器的輸出本身是外流面** ——
擋下的那一刻,祕密會被印進終端機、CI log、對話紀錄,
而那剛好是最多眼睛在看的時候。所以命中的那一段必須遮掉。

那條規矩當時解的是「**一次命中**」。本票是它的多命中形式:
**遮罩是逐命中做的,而洩漏是逐行發生的** —— 單位對不上。

> 同族形狀:分頁 API 每頁都過濾一次敏感欄位,但把所有頁併起來就還原;
> 日誌逐條脫敏,而多條日誌的交集反推出身分。
> **共同點:防護的單位小於攻擊者能取得的單位。**

## 修法方向(票內定奪,不預設)

1. **同一行有 ≥2 條命中就整行遮**,只保留行號與命中的 pattern 編號。
   最保守,代價是定位變難(而定位正是 F-067 特意保留的:「遮罩過頭 —— 前後文要留得住,否則定位不了」)。
2. **合併遮罩區間再輸出一行**:同一行的所有命中先聯集,遮完只印一次。
   保住定位、消掉拼回,但要處理區間重疊與相鄰。
3. 兩者混用:區間聯集後若**未遮比例過低**,退化成整行遮。

**判準:任意兩行報告併讀,不得比單獨一行洩漏更多。**
這句話要能被測試表達出來,否則修法無從驗收。

## 紅燈計畫

| # | 紅燈 | 守什麼 |
|---|---|---|
| 1 | 一行命中兩條 pattern → **併讀不可還原原始行**(現行可以) | 核心紅燈 |
| 2 | 三條以上命中同一行,同樣不可還原 | 兩條特例不算解決 |
| 3 | 命中區間**重疊**時不得產生「遮罩空隙」 | 區間運算的邊界 |
| 4 | **反控**:單一命中的輸出**維持 F-067 的形狀**(遮罩 + 前後文留得住) | 少了它,「整行全遮」也會讓 1–3 全綠,而那推翻了 F-067 |
| 5 | 個人 pattern 的**內容**仍然不印(只印編號) | F-067 既有保證,回歸 |

第 1 條的斷言形狀要小心:不能只斷言「輸出裡沒有完整祕密字串」——
拼回是**跨行**的,所以要**把該行的所有報告行併起來**再檢查。
單行斷言會給假綠,而假綠正是本票要修的東西。

## 落地紀錄(2026-08-14)

### 開場論證:**防護的單位小於攻擊者能取得的單位**

F-067 立的規矩解的是**一次命中**;而遮罩是**逐命中**做的,
洩漏卻是**逐行**發生的 —— **單位對不上**。

與票 21 是結構上的親戚:那邊是**逐 token 抽取**對上**整段語意**,
這邊是**逐命中遮罩**對上**整行洩漏**。
同族還有:分頁 API 每頁各自過濾而併頁可還原、日誌逐條脫敏而多條交集反推身分。

> 判準:**問「我防護的單位是什麼」與「對方拿得到的單位是什麼」,兩者不同就有洞。**

### F-080 前置:根因在 `scanner.py` 的逐命中迴圈

既有遮蔽實作是 `redact(text, matched)`(F-066/F-067),**它本身沒問題** ——
問題在呼叫它的那個三層迴圈:每個 `(行, 規則組, pattern)` 各產生一個 `Hit`,
各自只遮自己那一段。**不是遮罩壞了,是遮罩被用在錯的單位上。**

所以修法**不動 `redact`**,改成「先收齊這一行的所有命中,再決定怎麼遮」。

### 修法

| 命中數 | 行為 |
|---|---|
| **1** | **維持 F-067 原狀** —— 遮命中那一段,前後文留得住 |
| **≥2** | **整行遮**,訊息說明原因與命中數 |

多命中時前後文**不可能安全保留**:任何留下來的片段,
都是別份報告遮掉的那一半。定位改靠**路徑 + 行號** —— 那兩個本來就在 `Hit` 裡,
而且有一條測試釘住它們仍然正確。

### 取捨:整行遮 vs 區間聯集

票裡列過第二個方向(把同一行的所有命中區間**聯集**後遮一次,保住前後文)。
**沒有採用**,理由是它要處理區間重疊與相鄰,而**多一種遮罩路徑就多一種出錯方式** ——
而這條路徑的失敗方向是**洩漏**。

代價誠實寫出來:**多命中的那一行,F-067 的「前後文留得住」被犧牲了。**
只在多命中時發生,而那正是最不該保留前後文的情況。

紅燈:**2 紅 2 綠**(2 綠是 F-067 反控與行號定位 ——
少了它們,「一律整行遮」也會讓 2 紅轉綠,而那等於把 F-067 拆掉)。
修完 `tests/test_scanner.py` **23 passed**,全套 **687 passed / 0 failed**(+4)。
