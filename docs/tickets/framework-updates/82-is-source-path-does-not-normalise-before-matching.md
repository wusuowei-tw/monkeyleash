## 事實(實測,不是推論)

上一輪對三處「跳過某類路徑」判定各發一條唯讀探針,
問「換一種路徑寫法,它還認得出來嗎」。三處裡兩處乾淨,本處命中四筆:

```
scripts/../pkg/thing.py  -> 判成非原始碼(R2/R3 不管)   !! 危險方向
docs/../pkg/thing.py     -> 判成非原始碼                 !!
tests/../pkg/thing.py    -> 判成非原始碼                 !!
docs\..\pkg\thing.py     -> 判成非原始碼                 !!
```

反控成立(`pkg/thing.py` → 要管、`docs/x.py` → 跳過,分得出來),
邊界也對(`docsx/thing.py` → 要管)。

成因:`is_source_path` 取 `r.split("/")[0]` 當 top,**沒有先 normpath**。

## 這是 F-086 的標準形狀

`_is_scratch` 的 docstring **在同一個 repo 裡**逐字寫著:

> **先解 `..` 再比對。** 少了這一步,`C:/…/Temp/../../../../<目標>` 會命中片段
> → 豁免 → 放行……這與「許可前綴不能替後面那段背書」是同一條判準(F-051):
> **任何用子字串或前綴放行的地方都適用。**

而 `is_source_path` 自稱是「黑名單反轉後的**唯一判定點**」,
**它就是一個用前綴放行的地方**,而它沒有 normpath。

> **同一份判準寫在 A 模組的註解裡,不會讓 B 模組變安全 —— 註解不是機制。**

## 為什麼不選 B(先取樣再決定修不修)

**修法在兩種答案下完全相同。**
不論端到端能不能利用,`is_source_path` 對 `docs/../pkg/thing.py` 的答案
都是錯的 —— 那個路徑真的是 `pkg/thing.py`。
取樣能改變的是**嚴重度的敘述**,不是**要改的那一行**。
所以先取樣等於讓一個已知答錯的判定點多錯一輪,而換到的資訊不影響動作。

### ⚠ 但「normpath 失效方向往嚴倒」這句話**不成立** —— 實測

裁決令把這句當成上一輪回報的原文引用。**上一輪沒有這句話**
(上一輪寫的是「A 現在就動一個 fail-closed 判定點,B 多花一輪但知道自己在修什麼」)。
所以開票前把它當成一個**未驗宣稱**驗了一次。**唯讀探針量到 14 個輸入:**

| 方向 | 筆數 | 例 |
|---|---|---|
| 不變 | 10 | `docs/x.py`、`pkg/thing.py`、`../pkg/thing.py` |
| 變**嚴**(多管一個) | 2 | `docs/../pkg/thing.py`、`docs/` |
| 變**鬆**(少管一個) | **2** | `./docs/x.py`、`pkg/../docs/x.py` |

**所以它不是往一個方向倒,兩個方向都會動。**

**而這不是壞消息** —— 關鍵在於那兩筆「變鬆」都是**修正誤擋**:
`./docs/x.py` 與 `pkg/../docs/x.py` 的真實路徑**就是** `docs/x.py`,
判成跳過是**對的**;現況判「要管」才是錯的(誤擋)。

正確的說法因此是:

> **normpath 不是往某個方向倒,是讓判定對齊真實路徑。**
> 對齊之後**沒有新的漏擋面** —— 因為判成非原始碼的前提是
> 它正規化後**真的**在非原始碼目錄底下。

**這一段特地寫進票面**,因為「失效方向往嚴倒」是一句
**讀起來讓人放心、可以據此跳過風險複查**的話。
它剛好在這一次是安全的(結論相近),而**理由是錯的** ——
下一次有人拿「往嚴倒」去論證另一個改動,就不會再對。
(CLAUDE.md:正確的規則與正確的解釋是兩件事。)

### 動工時必須一併驗的邊界(探針已量,寫下來省一次重跑)

`posixpath.normpath` 對退化輸入**不丟例外**,所以沒有 fail 方向要談:

```
''  -> '.'        '.' -> '.'        '..' -> '..'       '///' -> '/'
'a\x00b' -> 'a\x00b'                '\\server\share\x.py' -> '//server/share/x.py'
'C:/x.py' -> 'C:/x.py'              '~/x.py' -> '~/x.py'
```

兩格要注意:
- **NUL 位元組原樣穿過** —— normpath 不會擋它,若別處靠它擋要另外處理
- `\\server\share\x.py` → `//server/share/x.py`,top 變 `''` → 判「要管」(安全方向)
