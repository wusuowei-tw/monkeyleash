## 現象(原始輸出)

```
$ python -X utf8 -m pytest "tests/test_gate.py::TestLegacyNoRedlightList::test_the_list_is_what_the_generator_would_produce" -q --no-header

E       assert not ['.claude/portable/g1_guard.py']
tests\test_gate.py:870: AssertionError
1 failed in 0.20s
```

該測試斷言兩個方向,**紅的是第二個**:

- 方向一(`entries <= expected`,只減不增)—— **綠**。
- 方向二(`expected - entries` 裡每一筆都要有合格紅燈紀錄可解釋)—— **紅**,
  `.claude/portable/g1_guard.py` 一筆。

⇒ 白話:`g1_guard.py` **在上線 commit 的樹裡**、**被判為原始碼**、
**不在凍結清單上**,而且 `redlight_missing()` 對它回非 None(= 沒有合格紅燈紀錄)。
