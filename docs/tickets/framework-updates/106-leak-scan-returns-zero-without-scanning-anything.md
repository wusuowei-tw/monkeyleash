## 一、問題

`.claude/portable/leak_scan.py:277-278` 逐字:

```python
277	        paths = [a for a in argv if not a.startswith("--")]
278	    return scan(paths, review=review) if paths else 0
```

**所有靜默出口都收斂在 `:278` 那一個 `else 0`。**

> ### **「掃過了,乾淨」與「一個檔都沒掃」回同一個退出碼,而且都零輸出。**

2026-09-04 實測:`python .claude/portable/leak_scan.py --help` →
**stdout 與 stderr 皆空,exit 0**。

### 三條路徑,而**只有兩條是缺陷**

| # | 路徑 | 現在 | 裁決 |
|---|---|---|---|
| **A** | **不認得的旗標**(`--help` / `--foo` / **`--stage` 打錯**) | `:277` 的 `not a.startswith("--")` 濾掉 → `paths == []` → **回 0,零輸出** | 🔴 **exit 2 + 訊息點名該旗標**(`--help` 例外,見裁四) |
| **B** | **零路徑**(完全沒給參數) | 同上 → **回 0,零輸出** | 🔴 **exit 2 + 訊息「沒有給任何路徑」** |
| **C** | **`--staged` 但 staged 清單為空** | 回 **0** | ✅ **明文維持 0**,並補負控釘住它 |

### 🔴 A 的失敗形狀比 B 更壞

**B 需要有人手動不給參數才會發生;A 只需要有人打錯一個字元。**

```

那一行**不會報錯、不會擋任何東西、退出碼 0** ——
`pre-commit` 的 `|| exit 1` 不會觸發,commit 照常成功,
而**洩漏偵測整層從此不在**,沒有任何東西會說。

這與 `manifest.py:101` 記過的那個形狀是同一族:

```

## 二、C 為什麼**必須**維持 0(**這一格是本票最容易做錯的地方**)

`git commit` 在零 staged 檔時本來就會失敗,所以 C 看似碰不到。**但它碰得到**:

| 情境 | 為什麼 `staged_paths` 回空 |
|---|---|
| `git commit --allow-empty` | 沒有任何異動 |
| **純刪除**(`D`) | `staged_paths` 用 `--diff-filter=ACM`,**`D` 不在裡面** |
| mode-only 改動 | 同上 |

而 `scanner.py:236-243` **已經把「問不到」與「真的沒有」分開了**:

```python
    if out.returncode != 0:
        raise StagedListingFailed(...)          # git 壞掉 -> 例外 -> main() 回 2
    ...
    if not paths:
        return []                                # 真的沒有 staged 檔 -> 空清單
```

其 docstring `:210-211` 逐字:

```
    **退出碼要看。** 不看的話,git 因為任何理由失敗 -> stdout 空 -> 清單空 ->
    呼叫端回 0 -> pre-commit 放行。權威層沒有 fail-open 的餘地。
```

⇒ **「問不到」早就回 2 了。C 回 0 是對的,不是漏網。**

### 🔴 把 C 也改成 2 會造出一個**永遠無法滿足的條件**

`scanner.py:219-222` 對 gitlink 記過**逐字相同**的教訓:

```
    「讀不到不等於乾淨」這條規則的正當性,對**應該是檔案**的東西成立;
    對 gitlink 它把「**沒有內容這回事**」判成「內容讀不到」,產生一個
    **永遠無法滿足的條件** —— 使用者沒有任何合法動作能讓它變乾淨,
    因為沒有東西可以洗。實測:下游因此連 bump 都做不出來。
```

**把 C 判成 2,就是把「沒有東西要掃這回事」判成「掃描機制壞了」** ——
使用者沒有任何合法動作能讓一個 `--allow-empty` 的 commit 變得「有檔案可掃」。

> ### **⇒ 釘住 C 比改 A/B 更重要。**
> 沒有那條負控,**下一個人會順手把三條都改成 2** ——
> 而那個改動讀起來會像「把 fail-closed 做得更徹底」。
