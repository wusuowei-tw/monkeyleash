# 164 R7 許可前綴的切段不認單一 & 與換行

**狀態**：候選（優先；票 158 這批推完先做）

## 問題

`SEGMENT_SPLIT_RE` 只切 `&&`、`||`、`;`、`|`；單一 `&`（背景執行）與換行不是切點。`git status & <任意指令>`、`git status`＋換行＋`<任意指令>` 整條只有一段、以許可前綴開頭 ⇒ `_bash_write_verdict` 在環境前綴與寫入判定之前就回 `allowed-prefix` 放行，量測也不記。〔讀碼推論，未實驗〕

- **命令替換也不是切點**（票 158 A-e B1，Jeff 2026-10-27 裁併入本票）：`$(…)`、反引號、`<(…)`／`>(…)` 裡的指令整個被當成外層那一段的一部分。`$(PYTHONPATH=x python x.py)` 首 token 不像指派 ⇒ 環境前綴檢查看不到；`git status $(…)` 整段以許可前綴開頭 ⇒ 更早就放行。〔讀碼推論，未實驗〕——2026-10-27 Jeff 裁 D：非許可前綴段內的命令替換語法**已由票 158 A-h 收掉**（`edb4179` 之後的 A-h2 commit）（擋為「無法解析」）；許可前綴段（`git status $(…)`）仍由本票的切段問題涵蓋。完成與否以票 158 A-h 定案為準。

## 影響

可能不只環境前綴，連寫入構造都一起放過——第一步要用唯讀讀碼與紅燈證實範圍。BASE 既有，不是票 158 引入。
