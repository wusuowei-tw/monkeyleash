## 一、要做什麼

**兩邊 `pytest --collect-only` 的清單取差集,逐條列出:**

1. **只在本機收集到的**
2. **只在 CI 收集到的**
3. **兩邊都收集到、但結果不同的**(skip / deselect / pass 各自哪些)

**然後才回頭解釋 `10` / `3` / `1` 這三個數字各自從哪裡來。**

**範圍就這一句,不擴。** 修不修那個差是另一張票的事 —— 本票只負責**讓那個差有名字**。

## 二、為什麼範圍不能寫成「列出那 10 支是哪 10 支」

**因為 10 可能不對應任何一個測試集合。** 把總收集數算出來就看得到:

| | 算式 | 總收集數 |
|---|---|---|
| 本機(票 83,2026-08-27) | 1043 passed + 3 skipped + 3 xfailed | **1049** |
| CI(monkeyleash `tests` #1) | 1033 passed + 3 xfailed + 1 deselected | **1037** |
| | | **差 12** |

⇒ **`10`(passed 差)、`3`(skip 消失)、`1`(deselect 出現)是三個獨立的差額**,不會自動加起來成一個故事。
`10 + 3 − 1 = 12` **只是恰好閉合 —— 那是算術,不是歸因。**

把票綁在 `10` 上的後果很具體:查完只會多出一句「10 支找不齊」,
而**下一個人不知道該去找 12 還是 13**。**先取差集,數字最後才解釋。**

### 順帶更正一個講錯的說法(舊文不刪)

~~「3 skipped 變成 1 deselected」~~ —— **這句把兩件事寫成一件,而且數字對不上(3 ≠ 1)。**

正確的寫法是**兩件事各自歸因**:**「3 個 skip 消失」** + **「1 個 deselect 出現」**。

- **skip**:collect 進來了,**跑的時候**才判定跳過
- **deselect**:**collect 之前**就被濾掉,根本沒進來

寫成「變成」會讓人以為是同一批東西換了個名字,**於是沒有人會再問** ——
這正是它兩次都沒被查的原因之一。

## 三、為什麼現在才立案(這一格是本票存在的理由)

**同一個差出現過兩次,兩次都只記了數字,沒有人列出是哪些測試:**

| 次 | 何時 | 本機 | CI | 差 |
|---|---|---|---|---|
| 1 | 票 75 | 972 passed / 3 skipped / 3 xfailed | 962 passed / 1 deselected / 3 xfailed | −10 |
| 2 | 票 84(2026-08-27) | 1043 passed / 3 skipped / 3 xfailed | 1033 passed / 1 deselected / 3 xfailed | −10 |

第二次**引用第一次**當作「這個差是已知的」,而**第一次從來沒有真的查過**。

> **數字對得上是好證據,但它同時也是危險的。**
> 再引用一次,它就會變成常識 —— **F-086 的第二半:落地紀錄會被引用,
> 而引用的人不會回頭重驗。**

而「我之後會跑一次 `--collect-only`」這種講法**沒有主詞**(F-110:
「要留存」寫了、東西沒留下),它已經在票 75 那裡失蹤過一次。
**所以這一格開成票,不留在意向。**
