### 它今天仍然成立(2026-09-03 實查)

而它們**只被三條測試消費,三條都不斷言「會擋」**:

|---|---|---|

> ### **三條裡沒有一條斷言 `msg` 裡有 `R1`。**
> 語料在、規則在、測試在,而「這條規則會擋」這件事**從來沒有被任何一條斷言問過**。

### 為什麼這一格特別容易被讀成已經有涵蓋

**因為語料在檔案裡。** 一個讀 `CORPUS` 的人會看到「規格書夾程式碼」那兩行,
自然推論它們是拿來驗 R1 會擋的 —— 而它們的實際用途是**結構不變式**。

> **輸入存在不等於斷言存在。** 兩者在同一個檔案裡、相隔四十行,
> 而**只有斷言那一半決定測試在測什麼**。

## 三、範圍:18 條正控

### 口徑(裁三逐字,不得改寫)

> **正控 18 條 = 16(8 樣式 × 2 路徑,content 直給)
> + 2(每條路徑各一條 content=None 真寫檔到 tmp_path 再讀)。**

**這句話要跟著數字走**(`F-109`:數字與基準一起寫)。少了它,
「18」會被讀成一個扁平的計數,而它其實是**兩個維度的積再加一個獨立的軸**。

### 8 個樣式的來源

`.claude/hooks/gate.py:186`:

```python
CODE_IN_SPEC_RE = re.compile(r"```|^\s*(def|class|import|from|function|const|let)\s", re.M)
```

| # | 樣式 | 觸發條件 |
|---|---|---|
| 1 | 圍籬 | **任何位置**都算(不受 `^` 約束) |
| 2–8 | `def` / `class` / `import` / `from` / `function` / `const` / `let` | `^\s*` + 關鍵字 + **一個空白字元**,`re.M` 逐行 |

### 2 條路徑的來源

`.claude/hooks/gate.py:1845`:

```python
    if r.startswith("docs/specs/") or re.match(r"^\.scratch/[^/]+/spec\.md$", r):
```

| # | 路徑 | 形狀 |
|---|---|---|
| A | `docs/specs/**` | **前綴**,底下任意深度 |
| B | `.scratch/<feature>/spec.md` | **完整比對**,`[^/]+` 只吃一層,檔名必須是 `spec.md` |

### 第三個軸:內容從哪裡來(那 +2 的理由)

`.claude/hooks/gate.py:1848-1857`:

```python
        body = content
        if body is None:
            try:
                with io.open(os.path.join(ROOT, r), encoding="utf-8") as f:
                    body = f.read()
```

**前哨給 `content`,commit 時 `content is None` 由 gate 自己從磁碟讀。**
讀不到那一支(fail-closed)**已經有正控**(`tests/test_gate_boundaries.py:39-50`),
而**讀得到且裡面有碼**那一格是唯一沒被驗過的 —— 所以每條路徑各補一條真寫檔。

## 四、範圍:4 條反控

| # | 反控 | 少了它會怎樣 |
|---|---|---|
| **1** | **純散文的規格書不得被擋**(兩條路徑各一) | 一支「凡是 `docs/specs/` 一律擋」的實作也會讓 18 條正控全綠 —— **那是把功能弄壞,不是修好** |
| **2** | **非規格書路徑不進判定**(`docs/agents/friction-log.md` 帶 `import`;`.scratch/f/issues/01-x.md`) | R1 會把每一份提到 `import` 的文件擋掉,而 friction log 正是**寫閘門行為的文件** —— 同一個形狀已經咬過一次(`_quote_spans` 的 docstring:G1 擋住了「描述 G1 擋了什麼」) |
| **3** | **前綴要帶邊界**:`docs/specsx/x.md` 夾程式碼不得被 R1 擋 | 現行 `startswith("docs/specs/")` **帶尾斜線所以是安全的**;這條釘住它。哪天有人改成 `startswith("docs/specs")`,它會紅。同族:`CLAUDE.md` 的常駐檢查項、`g1_guard` 的「前綴要帶邊界」 |
| **4** | **`.scratch` 那條只吃一層**:`.scratch/a/b/spec.md` 不進判定 | 正則若被改成 `.*`,它會紅 |

### ⚠ 第 4 條的性質(裁四要求逐字寫明)

> **它釘的是現行行為,不是理想行為;要不要支援多層是另一件事,本票不裁。**

**寫這一句的理由**:一條釘住現行行為的測試,讀起來與一條釘住正確行為的測試
**長得一模一樣**。不標明的話,下一個想把 `.scratch` 判定放寬的人會看到它紅,
然後以為自己違反了一條設計決定 —— 而它其實只是一份現況的快照。
