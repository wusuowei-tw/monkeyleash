## 三、範圍:18 條正控

### 口徑(裁三逐字,不得改寫)

> **正控 18 條 = 16(8 樣式 × 2 路徑,content 直給)
> + 2(每條路徑各一條 content=None 真寫檔到 tmp_path 再讀)。**

**這句話要跟著數字走**(`F-109`:數字與基準一起寫)。少了它,
「18」會被讀成一個扁平的計數,而它其實是**兩個維度的積再加一個獨立的軸**。

### 8 個樣式的來源

`.claude/hooks/gate.py:186`:

```python
CODE_IN_SPEC_RE = re.compile(r"```|^\s*(def|class|import|from|function|const|let)\s", re.M)
```

| # | 樣式 | 觸發條件 |
|---|---|---|
| 1 | 圍籬 | **任何位置**都算(不受 `^` 約束) |
| 2–8 | `def` / `class` / `import` / `from` / `function` / `const` / `let` | `^\s*` + 關鍵字 + **一個空白字元**,`re.M` 逐行 |

### 2 條路徑的來源

`.claude/hooks/gate.py:1845`:

```python
    if r.startswith("docs/specs/") or re.match(r"^\.scratch/[^/]+/spec\.md$", r):
```

| # | 路徑 | 形狀 |
|---|---|---|
| A | `docs/specs/**` | **前綴**,底下任意深度 |
| B | `.scratch/<feature>/spec.md` | **完整比對**,`[^/]+` 只吃一層,檔名必須是 `spec.md` |

### 第三個軸:內容從哪裡來(那 +2 的理由)

`.claude/hooks/gate.py:1848-1857`:

```python
        body = content
        if body is None:
            try:
                with io.open(os.path.join(ROOT, r), encoding="utf-8") as f:
                    body = f.read()
```

**前哨給 `content`,commit 時 `content is None` 由 gate 自己從磁碟讀。**
讀不到那一支(fail-closed)**已經有正控**(`tests/test_gate_boundaries.py:39-50`),
而**讀得到且裡面有碼**那一格是唯一沒被驗過的 —— 所以每條路徑各補一條真寫檔。

### ⚠ 第 4 條的性質(裁四要求逐字寫明)

> **它釘的是現行行為,不是理想行為;要不要支援多層是另一件事,本票不裁。**

**寫這一句的理由**:一條釘住現行行為的測試,讀起來與一條釘住正確行為的測試
**長得一模一樣**。不標明的話,下一個想把 `.scratch` 判定放寬的人會看到它紅,
然後以為自己違反了一條設計決定 —— 而它其實只是一份現況的快照。
