# 80 — G1 第二級:cygdrive 與 UNC 擷取不到 —— 兩個實測漏擋

**狀態**:open
**立案**:2026-08-25,票 79 對帳裁 4(開票或登記由 agent 判 → 開票)
**來源**:量化 live probe 2026-08-25 實測(與部署版同 sha256 直呼 `level2_hit`):
`rm -rf /cygdrive/d/x` → 放行 ⚠️、`rm -rf //server/share/x` → 放行 ⚠️
**方向**:**漏擋**(不出聲、真操作穿過)—— 與票 79 三條殘留(誤擋)方向相反,比誤擋重。

## 為什麼不等 F-050 實例

F-050 的「補擷取要有實際誤擋當證據」講的是**誤擋面** —— 誤擋看得見、
會被抱怨、等得到實例。漏擋不產生抱怨,等實例 = 永遠等下去。
本票的證據是主動探針(量化 F/G 兩案),不是抱怨 —— 這正是漏擋面
唯一等得到的那種證據。裁 4 已明確排除 F-050 適用性,本票不再重議。

## 三面,成本與確定度都不同,不得綁成一刀

- **cygdrive(`/cygdrive/d/x`)**:`_POSIX_DRIVE_MOUNTS` 共表加 `"cygdrive"`
  一格 —— 構造已為它留位(表旁註解:「加一個掛載點(如日後 cygdrive
  有實例)兩側同時獲得」),展開(`variants`)與收斂(`_canon`)同時獲得,
  雙向耦合測試(`TestVariantsAndCanonCoverTheSameForms`)自動涵蓋。近零成本。
- **bash 寫法 UNC(`//server/share/x`)**:要動 `ABS_PATH` 擷取,有設計風險:
  `//` 開頭與 URL(`https://…` 的 `//`)、協定相對寫法撞形;
  且 proj 通常是磁碟形式,UNC 幾乎恆判專案外 → 誤差偏擋方向,
  要對著票 79 裁決條件 b(路徑面不縮)想清楚再動。
- **PS 寫法 UNC(`\\server\share`)**:**未取樣**(量化明列無樣本,不做宣稱)。
  動手前先補樣本判現況,不隨 bash 側順手帶 —— 「想不到不等於不存在」
  的反面也成立:沒看過的現況不能當已知。

## 驗收(兩方向,參照物不同 —— 沿票 79 紀律)

- **方向 A(該新擋的擋了)**:量化 F/G 兩案原樣為負對照 → 修後擋下。
- **方向 B(原判定全不動)**:`LEVEL2_REGRESSION` 逐條 + 16 案探針 0 不符;
  另加:URL 散文(`git commit -m "見 https://…/x 那頁"`)與含 `//` 的
  正常指令不得新增誤擋 —— 這是本票自己可能製造的新誤擋面,先釘住。
