> 本票**原本**要立的題目是「界線 A 沒有機器在守,而這件事沒有被記下來」。
> **後半句是錯的,而我是在寫這張票的中途才查出來的。**

> |---|---|
> | **紀律**(界線 A) | 整棵 `~/.claude/` 樹 |
> | **機制**(G1 第一級保護清單) | 全清單 **34 條**,位於那棵樹底下的是 **3 條,而且都是個別檔案** |

>
> `F-148` 的處置是「**登記,不開票**」。
> **所以本票不是「發現了一件沒人知道的事」,是「那個已知的差集又發生了一次,
> 而登記不開票這個處置沒有攔住它」。**

> 這一格寫在最前面,是因為 `CLAUDE.md` 那條:
> **「推論鏈的品質保證不了前提;而前提越自然,越不會被驗。」**
> 「這件事沒被記過」是一個非常自然的前提,而它是錯的 ——
> 差一點就寫成一張看起來很完整、而**前提沒被驗過**的票。

**同一天、同一串指令裡,機器守的那條界線守住了,散文守的那條沒有。**

| `~/.claude/`(界線 A) | **票 88 §八之一的裁決 + README 的散文** —— **只有文字** | **沒擋住** |

```

```

回了**一行**:`2026-08-27 10:20  228  upstream-roots.txt`。

### **這是第三次,不是第一次**

票 88 §八之一逐字寫「**A 已經被證明失效兩次**」,並附一張兩列的表:

| 次 | 日期 | 破線的動作 | **G1 有沒有機會擋** | 為什麼 |
|---|---|---|---|---|
| 一 | 2026-08-28 | `ls -la ~/.claude/hooks/g1_guard.py*` | **有,而它漏了** | 第一級不展開 `~`(`F-139`,票 88 本體) |
| 二 | 2026-08-29 | `ls -la` 家目錄 `.claude` **目錄**(MSYS `/c/…` 寫法) | **沒有** | **那個目錄本身不在保護清單裡** |
| **三** | **2026-09-09** | **`find "$USERPROFILE/.claude" -maxdepth 1 -printf`** | **沒有** | **同第二次 —— 目錄本身不在清單裡,而且這次連 `~` 都沒用到** |

**第三次與第二次是同一個歸因,換一個寫法。**
`$USERPROFILE` 展開後是絕對路徑,**票 88 那個 `~` 缺口在這次根本沒被用到** ——
⇒ **修好票 88 對這一次沒有任何幫助**,那正是 §八之一「A 是**已知會漏**的止血」那句話的意思。

> **`CLAUDE.md`**:「修好一個偵測器之後回頭重掃既有資料 ——
> 新規則的第一次全量掃描,問的不是『以後會不會再犯』,是『**以前犯過幾次**』。」
> **這裡的答案是:三次,而且三次都是提出這條界線的人自己破的。**

## 真正的題目(**這才是本票**)

### **G1 的保護清單自己就住在它要保護的那個資料夾裡。**

`F-148` 已經指出差集要收(「**改涵蓋範圍,不是改邏輯**」),
而它沒有處理**收的時候會撞到的那個循環**:

```
g1_guard.py             住在  ~/.claude/hooks/
g1-protected.txt        住在  ~/.claude/          ← 清單自己
settings.json(掛載點)  住在  ~/.claude/
```

**把整夾加進清單,等於把「鎖」和「鑰匙」一起鎖進保險箱。**

**本票的內容就是這個循環怎麼解**,不是「要不要鎖」。

### 動工時要逐條回答的四格(**以下是問句,不是裁決**)

| # | 問句 | 目前已知 / 未知 |
|---|---|---|
| ① | G1 讀自己的清單,會不會被自己擋? | **未量。** `g1_guard.py` 是 hook 程序內用 Python 讀檔,不是發一條 Bash 指令 ⇒ **推測**不受影響。**這是推論,動工第一步就是把它變成量測** |
| ② | 鎖整夾之後,`ADR 0009` 的維護流程還跑得動嗎? | `.claude/portable/g1_verify.py` 的**全套驗收**要讀真清單,而它由 Bash 叫起來 ⇒ **會撞上第一級**(「不分讀寫」)。**看起來會斷,未量** |
| ③ | 第一級「不分讀寫」對這一夾是不是對的粒度? | 界線 A 的散文寫的是「不碰」,與第一級語意**剛好一致** ⇒ 粒度可能本來就對,**問題只在它沒被裝上** |
| ④ | 替代案:只加控制檔(`g1-protected.txt`、`hooks/`、`settings.json`),不加整夾 | 那樣 `find ~/.claude` **仍然會過**,而三次破線裡的**第二、第三次都是列目錄** ⇒ **這個替代擋不住已經發生過的那兩次**。要不要接受,是裁決 |

> **④ 是本票最容易做錯的地方。** 它讀起來像穩健的折衷,
> 而**折衷掉的那一半剛好是唯一真的發生過的破線形態**。
> (`CLAUDE.md`:「驗收清單天生偏向意圖,而破壞來自意圖之外」——
> 這裡的意圖是「保護控制檔」,而發生的事是「列目錄」。)

### 併記:本票不主張「散文沒用」

散文那條界線三次都**被寫下來了**,而且三次都是**破它的人自己找出來自首的**。
它的失效方式不是「沒人知道」,是 `CLAUDE.md` 那條:

> **「要留存」是祈使句,而祈使句沒有主詞。** ——
> 「agent 一律不碰」這句話,**不做的時候沒有東西會叫**。

而 `F-148` 的處置是「登記,不開票」,**那也是一句沒有主詞的話**:
差集要收,而**沒有指定誰去收**。**十一天後它又發生了一次。**
**本票存在的理由就是給那件事一個主詞。**
