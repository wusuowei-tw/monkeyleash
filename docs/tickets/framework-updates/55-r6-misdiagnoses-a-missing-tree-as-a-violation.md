## 現況證據

`gate.py:1160–1168`:

```python
rc = subprocess.call(["git", "cat-file", "-e", "%s:%s" % (go_live, p)],
                     cwd=ROOT, stdout=subprocess.PIPE, stderr=subprocess.PIPE)
...
if rc != 0:
    out.append("[R6] %s 不在機制上線 commit %s 的樹裡,不得列入紅燈豁免清單。\n"
               "     清單只減不增:新檔案要走紅燈,不是往豁免名單裡加。"
               % (p, go_live[:7]))
```

**非零 rc 有兩種原因,程式折成一種:**

| | 意思 | 現在說什麼 | 該說什麼 |
|---|---|---|---|
| ① 路徑不在那棵樹裡 | **真違規** | 「新檔案要走紅燈,不是往豁免名單裡加」 | 同左 ✅ |
| ② 那個 commit **不在這個 repo 裡** | **環境問題**(淺層 clone、歷史被改寫) | **同一句話** | 「go-live commit 在這個 repo 裡找不到 —— 檢查是不是淺層 clone」 |

### 實測(淺層 clone,本機重現)

```
git rev-parse --is-shallow-repository  -> true
git log --oneline | wc -l              -> 1
git cat-file -t 45a8d16                -> fatal: Not a valid object name 45a8d16
```

九個條目**全部**被判違規,每一條都輸出:

```
[R6] .claude/hooks/gate.py 不在機制上線 commit 45a8d16 的樹裡,不得列入紅燈豁免清單。
     清單只減不增:新檔案要走紅燈,不是往豁免名單裡加。
```

**「是後來手加的」是推論,不是量到的事實。**

## 為什麼不該躺在 backlog(三個條件同時滿足)

| 條件 | 內容 |
|---|---|
| **便宜** | 修法只有**一行的形狀**:進迴圈前先驗 `git cat-file -e <go-live>^{commit}`,不成立時給另一句訊息 |
| **有明確受害者** | **任何淺層 clone 上的每一次 commit** —— CI、`--depth` 取得的工作副本、下游的自動化 |
| **會主動誤導** | 見下 |

### 與其他 (c) 項的分別

> **其他 (c) 是「沒人在看」;這一則是「看了,而且指錯方向」。**

它會**主動把人推向刪清單條目** —— 那是讀到「新檔案要走紅燈,不是往豁免名單裡加」
之後最合理的下一步。而:

1. 刪掉之後,**一份本來正確的清單被改壞**
2. 而 **R6 仍然紅**(樹還是不在)
3. 於是人會繼續刪,直到清單空掉,**而它從頭到尾都是對的**

> **一個方向正確而理由錯誤的擋下,比不擋更耗人。**
> 不擋的話人自己查;擋了並給錯理由,人會先照著錯理由做,
> **而且做完之後現象沒變,他會以為自己做得還不夠**。

`fail-closed` 保證的是「**擋不擋**」,不是「**為什麼擋**」——
而**人是照理由行動的**,不是照擋不擋行動的。

## 為什麼不在原票修

票 54 是**裝 CI**。修 R6 要動**權威層規則的判定路徑** ——
那是每一次 commit 都會跑的程式碼,規模與「裝 CI」不相稱,
而且它需要自己的紅燈(至少兩條:淺層下給新訊息、正常違規下仍給原訊息)。

票 54 當下的正確處置是 `fetch-depth: 0`:**讓 CI 不要踩到它**,
而不是**在裝 CI 的過程中改權威層規則**。

## 已知代價(不修的話)

- 任何淺層 clone 上 **R6 擋下每一次 commit**,而且**九條理由全是錯的**
- 而錯的理由**看起來完全合理** —— 它是一句通順、具體、帶規則代號的判定
- 這個缺陷**本機結構上碰不到**(本機的 clone 一直是完整的),
  所以它只會在**別人的環境**裡出現 —— 而那個人手上沒有這份紀錄

## 本票不含

**解法設計不在本票。** 上面的「一行的形狀」是**範圍**,不是設計 ——
真正要決定的是:訊息怎麼寫、要不要一併檢查 `LEGACY_GO_LIVE` 以外的
同類 `git` 呼叫(`gate.py` 另有數處 `cat-file` / `ls-tree`,**同類入口要一起問**,F-083)。
