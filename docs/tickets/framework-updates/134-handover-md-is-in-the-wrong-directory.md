## 第一件 —— `handover.md` 住錯目錄

### 現象

`docs/agents/handover.md` 記的是**某個 repo、某個時點的工作狀態快照**
(日期、票號、機器、近期排序)。而**同類的東西住在 `docs/handover/`**,
那個目錄早就標 `skip`,理由逐字寫在 manifest 裡:

```
# 交接檔記的是**這一組人在這個時點的處境**(誰不在、哪些決定被推遲到回來之後),
# 那是 per-repo 的狀態,不是框架內容 —— 同 docs/tickets/ 的理由。
docs/handover/                  skip
```

⇒ **兩個語意同類的東西住在兩個目錄裡**,而其中一個住在 `docs/agents/`
—— 那個目錄的其他住戶(`issue-tracker.md`、`domain.md`、`friction-log.md`、
`adr-numbering.md`)**全部標 `copy`**,因為它們是框架知識。

`handover.md` 是那個目錄裡唯一標 `skip` 的檔案。
**分類是對的,位置讓分類看起來像例外。**

### 為什麼這件事值得一張票(而不是「就這樣吧」)

**一個目錄裡唯一的例外,會被下一個人當成先例。**
下一個在 `docs/agents/` 加檔的人看到「這裡有一個 skip」,
就少了一個「這個目錄是框架知識」的信號 —— 而那個信號是分類的**預設值**在靠的東西。

### ⚠ 本輪(2026-09-11)**刻意只改分類、沒有搬檔**

這是裁決,不是漏掉:

> **搬檔是結構整理,與「讓連紅四輪的 CI 回綠」是兩件事。**
> 綁在一起 = 讓一個**緊急修復**夾帶一個**非緊急變更**。

夾帶的代價具體是:CI 回綠那一筆 commit 會同時改動路徑,
於是「CI 為什麼回綠」與「檔案為什麼搬家」混在同一個 diff 裡 ——
而下一次有人 bisect 找 CI 狀態的變化點時,會撞到一個做了兩件事的 commit。

### 時鐘

**無硬時鐘,低優先度。不阻塞任何事。**
(照 `docs/agents/issue-tracker.md` 的時鐘欄規矩:說不出時鐘的票
**一律停在低優先、不排進任何順序** —— 說不出來不是失格,
規矩要的是**每張票都被問過這個問題**。本票被問過了,答案是沒有。)

### 動工時要想的(立案不定死)

  讓它落回 `docs/handover/` 的目錄規則)—— 而 manifest 的「最長前綴者勝」
  會自動涵蓋,所以搬完那一行**應該**要刪掉而不是留著。**未驗。**

## 第二件 —— `commander.md` 把「Jeff」寫死成角色名,而它現在標 `copy`

### 現象

`docs/agents/commander.md` 的內文把**特定人名**寫死成角色名,
而 2026-09-11 的裁決把它標 **`copy`** ⇒ **它會跟著安裝出貨到每一個下游。**

### 為什麼這不是分類錯誤

裁決的理由逐字:它描述的是**框架層的操作規則與角色方法論**,
換到另一個下游 repo 仍然成立 ⇒ 落在 `copy` 是對的。
**寫死人名是內容要泛化,不是分類要改。**

> 把它改成 `skip` 來「解決」人名問題,是**用一個分類錯誤去解一個文字問題** ——
> 而代價是那份方法論不再跟著框架走,也就是把一個可攜的資產弄成不可攜的。

### 時鐘

**第一個不是 Jeff 的使用者出現時**(接 `product-security` 那條既有登記)。

現階段兩個下游都是同一個人的 repo ⇒ **不構成問題**。
但寫下來是因為 CLAUDE.md 那條:
**「要留存」是祈使句,而祈使句沒有主詞** ——
「以後要泛化」如果只是散文,不做也不會有任何東西叫。
**這張票就是那個主詞。**

### ⚠ 沒有機制,只有這張票(明寫)

**沒有任何東西會在 `commander.md` 帶著人名出貨時出聲。**
`leak_scan` 的個人 pattern 清單(`~/.claude/leak-patterns.local.txt`)
理論上會擋人名進 commit,**但本輪沒有量它有沒有涵蓋這個字串** ——
而「它應該會擋」與「它擋了」是兩件事。

⇒ **候選機制(未裁、未開票)**:若個人 pattern 清單本來就該涵蓋這個字串,
那麼今天它沒擋下 `commander.md` 這件事本身是一個獨立的缺陷,
應該另外量、另外開票。**本票不假設它有守。**
