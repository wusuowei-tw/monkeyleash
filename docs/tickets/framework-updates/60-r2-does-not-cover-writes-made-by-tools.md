# 60 — R2 涵蓋 agent 的寫入,不涵蓋工具自己的寫入,而這個邊界沒有寫在任何地方

**狀態**:**candidate**
**立案**:量化同步輪(2026-08-19)。裁決方向 **(a)**,見〈裁決已定的方向〉。

## 現況證據

`sync.py --apply` 用 `io.open(path, "wb")` 直接寫目標 repo 的檔案(`sync.py:_write_bytes`)。
那條路徑**不經過 `.claude/settings.json` 的 PreToolUse hook** ——
前哨看得到的是 agent 的工具呼叫,看不到一個 Python 行程自己開檔案寫。

所以 **R2(「不是宣告 `allows_src_write` 的站就不准寫原始碼目錄」)對這條路徑完全不生效。**

2026-08-19 那一輪的實測推論:

> 八個步驟裡的步驟 1「開窗」(`idle -> implement`),**在寫入面上不是必要條件** ——
> 就算 `current_stage` 停在 `idle`,`sync.py --apply` 一樣寫得進去。

開窗真正的作用是**留下人為裁決的紀錄**(開窗、關窗各一筆 commit)。
**那是流程紀律,不是機制。**

## 這不是「sync 應該被 R2 擋」

sync 的職責就是覆寫框架檔。被 R2 擋住反而會製造票 19 那種死循環
(下游要新版工具才能發證,發證要淨樹,淨樹要先同步)。

**要修的不是行為,是那個邊界沒有被寫下來。**

> **「有閘門」與「這條路徑經過閘門」是兩件事。**

這是 CLAUDE.md 已載判準的鄰居:

- 已載:**「沒有入口」與「我沒去造入口」是兩件事,前者聽起來像事實。**
- 本則:**「受閘門管」與「這一次的寫入經過閘門」是兩件事,前者聽起來像全稱。**

共同點是**一句真話在讀者腦中補完成一句更強的假話**,而補完的那一步沒有人說出來。

## 權威層涵蓋得到嗎:涵蓋得到,但只在 commit 時

2026-08-19 的實測證據 —— 量化 commit `a16e97f` 觸發了 pre-commit 並印出:

```
[R2/自我修改豁免] .claude/hooks/gate.py:閘門自身,不受站別限制 —— 已記錄。
     理由:閘門把站別卡住時,修法需要改本檔;R2 管到它就把人鎖在外面(docs/adr/0004)。
     R3 沒有例外:寫測試不需要先解鎖任何東西。
```

同一輪 `.dev/gate-exemptions.jsonl` 新增 6 筆,`stage=implement`、`at_commit=true`。

所以 sync 寫進來的東西**進版控時照樣受審**。
缺的是**寫入當下**那一層,而 CLAUDE.md 把那一層描述成前哨的職責。

> **兩層都在,只是第一層對這條路徑是空的** —— 而空的那一層不會出聲說自己是空的
> (與 CLAUDE.md 卷首「權威層未安裝時完全靜默」同一個形狀)。

## 裁決已定的方向:(a)

| | 做法 | 代價 | 裁決 |
|---|---|---|---|
| (a) | CLAUDE.md 的 R2 那一列補一句邊界說明 + `sync.py` 檔頭寫明「這是設計不是缺陷」 | 註解不是機制 —— 但這一張要修的**本來就是文字**,不是行為 | **採用** |
| (b) | 讓 `sync.py --apply` 自己讀 `pipeline.json`,不是宣告站就拒絕 | 把票 19 的死循環風險帶回來,需要一併設計豁免;而**它會把一個刻意的設計改成一個要被繞過的限制** | 不採 |

(a) 的兩半**都要做,而且理由不同**:

- **CLAUDE.md 那半**防的是**讀者推論過強** —— 讀 R2 的人以為所有寫入都受管
- **`sync.py` 檔頭那半**防的是**下一個人把它當缺陷去修掉** ——
  一個沒有寫下理由的例外,在下一次審查時看起來就是漏網

第二半是這一張真正的價值。**「把『這是設計』寫下來」與「把缺陷記下來」是兩種不同的文件動作**,
而只做第一半的話,下一個人會照著 (b) 去修,然後撞上票 19。

## 已知代價(不修的話)

- 「開窗才寫得進去」這個假信念會繼續存在,而由它推出的**「沒開窗就是安全的」是假的**
- `sync.py` 這個例外沒有記載,下一次審查會把它當漏網去補,然後重新製造票 19 的死循環
- R2 在文件上看起來是全稱命題,而它不是 —— **而讀者無從得知**

## 本票不含

- 改變 sync 的實際行為(裁決已否決 (b))
- 其他同樣繞過前哨的工具路徑盤點 —— **那是個好問題,但它是票 61 那一類的唯讀盤點**,
  不在本票。(CLAUDE.md:「收了一個入口,就回頭問它的同類入口在哪」——
  `install.py`、`user_layer.py`、`verify_gates.py` 都會寫檔案。)
