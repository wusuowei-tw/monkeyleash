# 70 — sync 的搬遷守衛只抽 `##`,而作者的寫作單位不是 `##`

**狀態**:**candidate**(立案,不動工)
**立案**:2026-08-21,上游午後輪 A1 裁決
**來源**:量化 `TSI-038`(量化 repo `docs/agents/friction-local.md`)

---

## 範圍(先收在可落地半)

**本票做的**:把 `sync.py` 的搬遷守衛從「比標題號碼的集合」換成看得見
「既有標題底下的追加」的判準,並保住「**是哪一則**」這個診斷。

**本票不做的**:替 `copy` 桶裡**其他**檔案裝守衛 —— 那是票 66。

> **與票 66 的關係寫在這裡,不是散在兩邊。**
> 票 66 的題目是**範圍**(守衛只裝在 friction-log 上,而 `copy` 桶裡不只它會被下游寫);
> 本票的題目是**顆粒度**(那道已經裝上的守衛,看不見它保護的檔案裡的一整個層級)。
>
> 兩張的機制**可能**共用同一個面:票 66 傾向 provenance(「這個檔案自從我上次寫它之後
> 有沒有被動過」),而那個判準不解析格式,所以它**也**答得出本票的現象。
> **若票 66 落地並吸收了內容層,本票剩下的診斷半仍然成立** ——
> 「有沒有被動過」答不出「被動的是哪一則」,而 friction-log 的出口
> (搬去 `friction-local.md`)需要後者。

**為什麼不併進票 66**(三條,立案時裁決):

1. **票 66 卡在「拒絕之後的出口是什麼」,而本票沒有那個卡點。**
   票 66 自己寫著「這一題比機制本身重要」——ADR 沒有對應的「本地檔」概念。
   friction-log **已經有出口**(`friction-local.md`),所以本票可以先落地。
2. **兩張動的東西不同**:票 66 要**新增**一道守衛;本票要**修**一道已經在跑的守衛,
   而那道守衛正在保護一個每一輪都在被寫的檔。
3. **票 66 的落地驗收已經從 0 長到 2 項。** 第 3 項會讓它更難落地,
   而「更難落地」對一張止血中的票是實質代價(`docs/adr/` 目前標 `ask` 止血)。

## 現況(機器事實)

`.claude/portable/sync.py` 的 `HEADING` 常數逐字:

```python
HEADING = re.compile(r"^## (\S+)", re.M)
```

消費它的只有 `_headings(path)`,而 `_headings` 的消費者有兩個:

| 消費者 | 它問的問題 |
|---|---|
| `refuse_if_duplicate_headings(path, whose)` | 同一個號碼有沒有出現多次 |
| `unmigrated_friction(src, target)` | 目標有、來源沒有的條目(`sorted(th - sh)`) |

**兩個盲點,不是一個:**

1. **層級盲** —— `^## ` 只認二級標題。`#` / `###` / `####` 一律看不見。
2. **追加盲** —— `(\S+)` 只取標題的第一個 token,而差集比的是 token 的集合。
   下游若在**既有的 `## F-xxx` 底下追加內容、不開新的 `##`**,
   `th - sh` 是空集合,`unmigrated_friction` 回 `[]`,dry-run 一個字都不印。

**`TSI-038` 走的是第 2 條**(它的標題是 `### 實例 2`,同時踩中兩條)。

### 上游自己這一份就已經在盲區裡

`docs/agents/friction-log.md` 的標題層級分佈(以 `e7fd1ce` 實測,單位是標題行):

| 層級 | 行數 |
|---|---|
| `^## ` | 104 |
| `^### ` | 18 |
| `^#### ` | 4 |

→ **22 個標題行是守衛看不見的**,而且這是上游自己的檔案,不是下游才有的形狀。

## 標本(兩個,都現存)

### 標本一:`TSI-038` —— 27 行被靜默遷出

量化於 `d898da5`(2026-08-20)往**框架份**(標 `copy`)的 `## F-100` 底下加了內容。
`git show --stat d898da5 -- docs/agents/friction-log.md` 逐字:

```
 docs/agents/friction-log.md | 27 +++++++++++++++++++++++++++
 1 file changed, 27 insertions(+)
```

量化 `TSI-038` 的「為什麼護欄抓不到」欄逐字:

> **只抽二級標題**,而 `unmigrated_friction()` 拿它做
> `set(target) - set(source)`。這 27 行的標題是 `### 實例 2` —— **三級**。
> 於是差集是空的、`sync --apply` 放行,然後**靜默刪掉這 27 行,不會有任何訊息**。

**擋下它的不是守衛** —— 量化 `TSI-038` 的發現欄逐字:
「**不是護欄告訴我的 —— 護欄看不見它。**」

### 標本二:同形態的第二個現存實例

量化 `friction-local.md` 的 `TSI-034` 底下另有一個 `### 實例 2` 標題
(`實例 2(2026-08-20):裸票號指向另一個 repo 的票`)。

**它沒有被刪的風險** —— `friction-local.md` 標 `generate`,不是 `copy`。
記它的理由是**形態**:同一個寫作單位(`### 實例 N`)在同一個作者手上出現第二次,
所以那不是一次意外的寫法,是**這個 repo 裡人實際的寫作單位**。

> 立案時裁決:**寫進本票,不另發號。**
> 它不是一則新的摩擦,是本票標本的第二個資料點。

### 為什麼這一族比撞號那兩次更難發現

量化 `TSI-038` 逐字(值得整段引,它是本票最好的一句):

> 前兩則的受害者是**一整則條目**(有標題、有號碼,少了看得出來);
> 本則的受害者是**一則條目的一段**,而**上游那則條目還在**。
> 同步後打開檔案,`## F-100` 好端端地在那裡 —— 少掉的是它底下的第二個標本,
> 而沒有人記得那裡本來有兩個。**存在的東西會被檢查,不存在的東西不會。**

## 設計方向(兩層。定稿設計在動工時提案,不在本票)

### 內容層 —— 主判

**逐 `##` 區塊比內容:同名區塊兩邊不同 ⇒ 目標有本地追加。**

- 直接答得出 `TSI-038` 的實際形狀(既有標題底下追加),**因為它不看標題層級**。
- 順帶答得出「**是哪一則**」—— 差在哪個 `## F-xxx` 區塊是直接的輸出,
  而那正是出口(搬去 `friction-local.md`)需要的診斷。
- 開放的問題(動工時要答):上游自己修改某則的正常增長會不會誤觸?
  差集要不要只看「目標有而來源沒有的行」而不是「兩邊不同」?

### 結構層 —— 診斷補充

**來源沒有的標題層級 / 標題,列進訊息裡當定位線索。**
不當主判 —— 主判交給內容層,結構層只負責讓人快點找到位置。

### ⚠ `^#{2,3}` 這條路已被機器否決 —— 寫在這裡防止重提

顯而易見的修法是把 `HEADING` 放寬成 `^#{2,3} `。**它在第一次 sync 就會炸。**

實測(`e7fd1ce`,上游自己的 friction-log):

```
$ grep -oE "^#{3} \S+" docs/agents/friction-log.md | sort | uniq -c | sort -rn
      2 ### ⚠
```

`### ⚠` 已經出現兩次。而 `refuse_if_duplicate_headings` **先跑**
(`unmigrated_friction` 內部第一件事就是先驗號碼唯一,順序不能反),
於是放寬層級之後,sync 會對**來源檔**拒絕,訊息是
「這份表無法用來判斷哪些是本地條目」。

**這不是誤報風險評估,是當場必紅。**

根因是 `^#{2,3}` 假設了一件不成立的事:**三級標題是識別碼**。
它們不是 —— `### ⚠`、`### 事實`、`### 累積計數` 都是敘述,不是號碼。

### `####` 的遞迴,以及為什麼它不是「再放寬一層」就好

量化 `TSI-038` 的處置欄逐字:

> **只把 `##` 改成 `^#{2,3} ` 是把問題往下推一層**,
> 下次有人寫 `#### 實例 3` 會原地重演。

**任何固定的層級上限都是一個閉區間** —— 而寫死結尾編號的問題,
這個 repo 已經在規則代號上付過一次代價(見 `gate.py` 的 `rule_codes()` 那條規矩)。
內容層之所以是主判,理由就在這裡:**它沒有層級這個維度,所以沒有上限要選。**

## 可複用句(來源:量化 `TSI-038`,升格時一併帶走)

> **設計一道「找出對方沒有的東西」的護欄時,要問的不是
> 「它比對得對不對」,是「它切分的單位,和人實際寫作的單位是同一個嗎」。**
> 兩者一旦不同,差集會安靜地漏掉整個層級,而**漏掉的那一層不會出現在任何輸出裡**。

這一句與 `refuse_if_duplicate_headings` 自己的 docstring 是同一族:
那一則講「護欄用的資料結構對它的獵物不可見」(集合塌掉同號多則),
本則講「護欄用的**單位**對它的獵物不可見」。
**兩次都是護欄看世界的方式出問題,不是比對寫錯。**
