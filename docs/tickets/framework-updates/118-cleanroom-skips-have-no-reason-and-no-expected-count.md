## 事實(實測,2026-09-08)

`.claude/portable/verify_gates.py:380` 跑巢狀 pytest 的那一行:

```
380:    rc, out = sh([sys.executable, "-m", "pytest", "tests/", "-q"], target, check=False)
```

**`-q` 而且沒有 `-rs`。** 後果:CI log 裡看得到 skip 的**計數**,看不到**理由**。

CI run `34180144494` 的淨室那一步,逐字只有這一行:

```
pytest	淨室驗證(每條規則各擋一次 + 安裝後形態)	2026-09-08T02:28:56.0461112Z     1408 passed, 4 skipped, 3 xfailed in 13.24s
```

**那 4 個 skip 是什麼、為什麼 skip,log 裡一個字都沒有。**
票 114 那一輪要拿到理由,是在 `verify_gates` 留下的淨室 repo 上**手動補跑** `-rs`:

```
$ cd <淨室 repo>
$ python -m pytest tests/test_ticket_dirs_are_md_only.py -q -rs
SKIPPED [4] tests\test_ticket_dirs_are_md_only.py:169: 此 repo 沒有票目錄(`docs/tickets/` 在 portable-manifest 標 skip,不隨安裝出貨;`.scratch/<feature>/issues/` 也不由安裝器建立)—— 本檢查不適用。…
12 passed, 4 skipped in 0.07s
```

**⇒ 票 114 做的「loud skip」,在 CI 上只 loud 了一半。**

## 為什麼這是缺口(兩層,分開講)

**一、loud skip 的意義是「分得出『不適用』與『壞掉』」,而 CI 上分不出來。**

票 114 特地把理由寫進 skip 訊息(還加了一條測試釘住訊息內容),
理由是:「只寫 `skipped` 的話,一個真的壞掉的環境看起來與一個正常的新 repo 一樣。」
**而 CI 顯示的正是「只寫 skipped」。** 那條訊息在最需要被讀到的地方讀不到。

**二、`skipped` 的數字沒有預期值 ⇒ 會靜默漂移。**

`passed` 的數字每次回報都會被對帳(加數、底數、逐檔),**而 `skipped` 從來沒有**。
今天是 4;明天有人寫出一條「因為環境判斷寫錯而永遠 skip」的測試,
它會變成 5,**而沒有任何東西會說話** —— 那條測試從此不執行,
在輸出上與「它不存在」長得一模一樣。

> **一條 skip 掉的測試與一條沒寫的測試,在輸出上長得一模一樣。**

這與 `F-032`(綠的原因不是你以為的)是同一條線的第三型:
假綠、假紅、**與「沒跑而看起來像跑了」**。

## 兩個修法候選(**立案時刻意不定死**)

| | 做法 | 得到什麼 | 代價 / 疑慮 |
|---|---|---|---|
| **甲** | `verify_gates.py:380` 加 `-rs` | **便宜**,理由在 CI log 上看得到 | 仍然只是「印出來讓人看」,**沒有機器在管**。而淨室輸出會變長,所有既有回報的形狀跟著變 |
| **乙** | **枚舉**:斷言淨室裡預期 skip 的就是那幾條,**新出現的 skip 直接紅** | 有機器在管;新增一條壞掉的 skip 當場咬 | 清單要維護,**而清單本身要有理由欄**(否則一年後沒人知道某一筆為什麼在上面) |

**乙的依據是 `F-087`**,`CLAUDE.md` 的常駐檢查項逐字:

> **動手守一個面之前,先問這一面的集合是開放還是封閉。**
> 封閉且可窮舉時,**枚舉勝過比對** —— **比對的漏是未知的,枚舉的漏是不存在的**。
> **對封閉集合用 pattern 不是防線弱,是選錯工具。**

**淨室裡的 skip 是封閉且可窮舉的**:它們全部來自框架自己的 `copy` 桶測試,
數量是個位數,而且每一條都有具名的理由。**這正是該枚舉的形狀。**

## 待答(要一起裁的)

**甲與乙是不是該一起做?**

初步的想法(**不是裁決**):兩者服務的對象不同 ——
**甲給人看**(出事時 log 上直接有理由,不必去重跑),
**乙給機器管**(集合漂了當場紅)。
只做乙的話,紅了之後人還是要自己去查是哪一條;
只做甲的話,回到「印出來讓人看」而沒有東西在管。

**而「兩個都做」的代價是兩份維護**,所以這一格要裁,不要預設。
