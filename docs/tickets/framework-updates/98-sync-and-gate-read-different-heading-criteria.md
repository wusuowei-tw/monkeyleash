## 一、現象與證據(2026-08-31 晚實測)

對影音跑 `sync.py` 的 dry-run(不帶 `--apply`),**原始 stdout 逐字**:

```
[更新/拒絕] 來源 的 docs/agents/friction-log.md 有重複的條目號碼,這份表無法用來判斷哪些是本地條目。
     缺的前提是**號碼唯一**:差集看不見同號多則,
     於是本地那一則會被靜默刪掉(票 17)。
     同號的兩則是兩件不同的事,要分辨它們得讀內容 —— 那是人的判斷。
     併記於 出現 2 次,在第 4278、6159 行
exit=1
```

**那兩行**:

```
第 4278 行  ## 併記於 F-118(2026-08-26):**那次相撞真的發生了**          ← 7311d72  2026-08-26
第 6159 行  ## 併記於 F-145(2026-08-29):**裁決者側採用的處置 —— …**      ← c5e3c76  2026-08-29
```

**`F-118` 與 `F-145` 是兩個不同的號碼。** 撞的是解析器抓到的那個詞:`併記於`。

### ⚠ `sync` 沒有壞

`exit=1` + 說出缺的前提 = **fail-closed 正確作動**。
壞的是**判準的對象**:它把 `併記於` 當成一個條目號碼。
**⇒ 修法不得是「放寬它」。**

### 這個誤判從 2026-08-29 起就存在,而沒有人發現

第二行是 `c5e3c76`(8/29)進來的 —— **sync 從那天起一直被擋著,因為沒有人跑過 sync**。

## 二、🔴 乙族不是甲族:兩邊讀的不是同一份判準

| | 位置 | 正則 | 語意 |
|---|---|---|---|
| **R9(權威層)** | `gate.py:1283` `_FRICTION_HEADING` | `^##\s+([A-Za-z]+-\d+)(?:\s|$|[^\w-])` | **嚴**:前綴必須是字母、號碼必須緊接 `## ` |
| **sync** | `sync.py:38` `HEADING` | `^## (\S+)` | **鬆**:`## ` 之後第一個非空白詞就是號碼 |

**而 `gate.py:1283` 上面那段註解,把今天這件事逐字預先寫出來了**:

```
# 發號用的標題行:`## F-123 …`、`## TSI-038 …`。
# **前綴必須是字母、號碼必須緊接在 `## ` 之後** —— 這兩個條件一起,
# 把「發一個號」與「提到一個號」分開:
#   `## F-118 甲`                 -> 發號,算
#   `## 併記於 F-118(…):乙`      -> 提到,不算(號碼不在開頭)
#   `見 F-005 與 F-005 的討論`     -> 提到,不算(不是 `## ` 開頭)
# 本檔自己就有一段 `## 併記於 F-118(…)`,它刻意寫成這樣正是為了不被本條誤判。
```

> ### **`## 併記於 …` 這個寫法不是巧合,是為了躲開 R9 而刻意選的 ——
> ### 而 sync 抓到的正是 R9 刻意排除的那一類。**

**⇒ 修法 = 讓兩邊看同一份判準**,不是各自調鬆緊。

## 🔴 八、紅燈紀律:**本票的紅燈必須記在本票號下**

`tests/conftest.py` **自動**把每一次 pytest 執行寫進 `.dev/test-runs.jsonl`,
欄位裡的 `ticket_id` 取自 `.dev/pipeline.json` 的當下值。
而 R3 的判定(`gate.py:1473`)逐字是:

> 「%s 有紅燈紀錄,但沒有一筆屬於當前票 %s。
>      **舊票的紅燈不解鎖後續修改 —— 每張票要有自己的紅燈。**」

**⇒ 動工前 `.dev/pipeline.json` 的 `ticket_id` 必須先切到 `98`,而那一步由 Jeff 做。**

### 順序不可反,而且反過來的錯是靜默的

**票 → 切指標 → 紅燈**,不是「切指標 → 票」。
**票不存在就先改指標 = 製造一筆指向不存在東西的紀錄**(2026-08-16 先例)。

而在**沒有切指標**的情況下跑紅燈,後果**不是被擋,是不會被擋**:
那筆紅燈會寫成前一張票的號碼,格式全對、R3 放行、CI 全綠,
**而本票名下一筆紅燈都沒有** —— 更糟的是,它將來會替**那張前一票**的修改解鎖。

**⚠ 2026-09-01 實測**:本票立案當下 `pipeline.json` 的 `ticket_id` 是 `82`,
而當天已有 **33 筆**執行紀錄記在 `82` 名下。**本票動工前必須先切。**
