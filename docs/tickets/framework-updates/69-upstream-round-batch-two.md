## 開工時實測推翻的三件登記(**動工內容因此改變**)

### ① A4 的單位錯了:是 **1 個字串**,不是三個

登記寫「三條 `xfail` 的**三個** `reason` 字串」。實測:

```
$ grep -c "pytest.mark.xfail" tests/test_g1_guard.py
1
```

`tests/test_g1_guard.py` 只有**一個** `@pytest.mark.xfail` marker,
帶**一個** `reason=` 字串,底下 `@pytest.mark.parametrize("path", ["/srv/x", "/data/x", "/backup/x"])`
→ **3 個 xfail 實例**。而那一個字串裡「票 04」出現 **2 次**。

**單位對照**:1 marker / 1 reason 字串 / 2 個裸票號出現 / 3 個 xfail 實例。

> **算術錯會被看出來,單位錯不會**(CLAUDE.md)。
> 這一則從量化 `TSI-034` 實例 2 寫下、經上游輪盤點、再經批一收尾報告
> **三手都寫成「三個字串」而沒有人去數 marker** ——
> 因為 pytest 輸出裡確實有三行 XFAIL,而那三行**共用同一個 reason**。
> **一個看起來很像在數的東西,不一定在數同一件事**(F-104)。

形式照本檔其他地方的 `<使用者家目錄>`:

```
[G1/保護清單] 這個指令碰到受保護的路徑:<使用者家目錄>\.claude\hooks\g1_guard.py
     清單:<使用者家目錄>\.claude\g1-protected.txt
     第一級無豁免,也不分讀寫 —— 判定不解析指令,因為解析會失敗,
     而失敗的解析就是洞。要動這個目錄,請自己開終端機做。
```

> **標題從「原始擋下訊息」改成「擋下訊息」是刻意的。**
> CLAUDE.md 要求附**原始**擋下訊息、不轉述 —— 而這裡做了一次替換,
> 那它就不再是原始的。**做了替換卻仍稱原始,比替換本身糟**:
> 下一個人會拿它去逐字比對,然後在一個不存在的差異上查半天。

> **為什麼第 4 項不能被第 3 項取代。** `g1_verify` 自己 `subprocess` 起 guard,
> **不經 `~/.claude/settings.json` 的掛載**。所以它證明的是「如果被呼叫,它會擋」,
> 證明不了「它會被呼叫」。README 那條判準的逐字實例。

### 「18 條」這個數字已經過期

`docs/adr/0009` 第 2 步與 `CLAUDE.md` 的 G1 段都寫「跑 G1 那 18 條驗收」。
