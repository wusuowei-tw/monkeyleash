而這一族的每一次現身都是「拿 A 的東西當成 B 的證據」。

## 修法(已執行)

為 agent-gates 生成**它自己的**清單:10 筆、`# go-live: 5180678`、
內容由生成器算出(`git ls-tree 5180678` ∩ `is_source_path`),**不是手打的**。

落地路徑刻意分兩步:**生成器只印、由 Write 工具寫檔** ——
用腳本直接寫會繞過檔案工具那一層的判定,而那正是 R7 存在的整條理由。
「內容是機器算的」與「寫入走受管道」兩件事同時成立。

三條理由:

1. **對守衛檔要求「出生前紅燈」= 要求不可能的歷史。** 那 10 支在根 commit
   的樹裡就存在,而排水判定只認「紅燈時實作不存在」,**永遠排不掉**。
   與 **F-0014「上游自己做不到的紀律不得要求下游」同尺**。
2. **零筆會造成永久紅** —— F-031 / F-071 明文禁止。永遠紅的測試會教人
   「這套測試本來就紅」,代價是整套被忽略。
3. 三個減輕因素:
   - 只豁免 R3 **後半**(紅燈紀錄);前半「對應測試檔須存在」**照常適用**
   - 清單**只減不增**、凍結於 `5180678`;排水方向是移除,不是新增
   - 這 10 筆正是 `install.py` 對任何目標 repo 的標準產物 ——
     建立它等於 agent-gates 終於自己吃自己的狗糧(**ADR 0010** 的自我治理實踐)
