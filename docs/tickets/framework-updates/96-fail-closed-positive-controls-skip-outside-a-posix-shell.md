## 一、事實(2026-08-31 實測)

**即使已經用 Git Bash 跑過 `bootstrap.sh`**,在 **PowerShell** 下跑 `pytest`,
`tests/test_bootstrap.py` 仍有 **5 條 SKIPPED**。

成因在 `tests/test_bootstrap.py:144-150`:

```python
SH = shutil.which("sh")
needs_sh = pytest.mark.skipif(
    SH is None,
    reason="這台機器上找不到 sh —— **三道 fail-closed 的行為正對照整組沒有執行**。"
           "結構斷言仍然跑得到,但「它真的會擋」這件事在本機沒有被證明過"
           "(monkeyleash framework-updates/16)。")
```

## 二、🔴 重點**不是 skip 本身**

> ### **skip 訊息自己說了:「它真的會擋」這件事在本機沒有被證明過。**

那句話**寫得完全正確**,而且照票 16 主動出聲了 —— **問題是它出聲之後,沒有人接。**

**這與票 27 是同一族**:

| 票 27 | 本票 |
|---|---|
| `CLAUDE.md` 寫著「未安裝的副本上這句不成立」 | skip 訊息寫著「它真的會擋在本機沒被證明過」 |
| 而 agent-gates 自己就處在那個狀態,40 個 commit 沒人發現 | 而這 5 條在**任何沒有 `sh` 的殼**下永遠 skip |

> 票 27 補的是後者的第一半,本票問的是第二半。
